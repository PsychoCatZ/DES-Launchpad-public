# DES Launchpad

Локальная панель запуска для Windows 11: приложения, установленные браузерные приложения (PWA) и ссылки в отдельном растягиваемом окне. Создана в НИИ ИИ DES / КотоИмперии. Tauri v2, Rust и HTML/CSS/JavaScript. Версия 0.2.1. Лицензия MIT.

Публичный репозиторий: [PsychoCatZ/DES-Launchpad-public](https://github.com/PsychoCatZ/DES-Launchpad-public). Эта копия не содержит персонального списка приложений, ярлыков, журналов или истории приватного репозитория. Первый запуск открывает пустой список.

## Возможности

- Фиолетовый значок в трее; отдельное окно с максимизацией и группами приложений.
- Светлая, тёмная и системная темы, компактные плитки.
- Горячая клавиша (по умолчанию Ctrl+Alt+D), скрытие после запуска, добровольный автозапуск Windows.
- Запуск собственных копий ярлыков Windows, EXE с аргументами, HTTP(S) URL в app-mode Chrome или Edge.
- Крестик скрывает окно; завершение — через меню трея.

Мониторинг серверов и оборудования, поиск, перетаскивание и графический редактор списка приложений в эту версию не входят. Список редактируется в JSON.

## Сборка

Нужны Windows 11, Node.js/npm, Rust с MSVC toolchain, Visual Studio Build Tools с инструментами C++, Windows SDK и Microsoft Edge WebView2 Runtime. Инструменты сборки нужны разработчику; установленной программе нужны Windows и WebView2. Для запуска плиток должны существовать соответствующие приложения и браузеры.

```powershell
npm ci
npm run check
npm test
npm run build
```

`prebuild` создаёт пустой `local/apps.json`, папки `local/icons` и `local/shortcuts`, если их ещё нет. NSIS installer появляется в `src-tauri/target/release/bundle/nsis`. Для переносимой папки после сборки:

```powershell
pwsh -NoProfile -File scripts/package-portable.ps1
```

Папку переносимой версии следует копировать целиком, вместе с `defaults`. Запустите des-launchpad.exe; при необходимости создайте ярлык уже на своём компьютере. Для разработки: `npm run dev`. `--show` показывает окно, `--background` оставляет только трей.

Публичная сборка называется DES Launchpad Public и использует отдельный идентификатор `ru.kotification.des-launchpad.public`, чтобы не читать и не менять настройки персональной версии. Пользовательские данные находятся в `%APPDATA%\ru.kotification.des-launchpad.public`: `apps.json`, `settings.json`, `icons`, `shortcuts`, `launchpad.log`. Не включайте эти данные в Git. Если две версии работают одновременно, задайте им разные горячие клавиши.

## Добавление приложений

Откройте папку данных через настройки панели. Скопируйте нужный `.lnk` в её подпапку `shortcuts`, при необходимости PNG в `icons`. Затем отредактируйте `apps.json` и нажмите перезагрузку конфигурации в настройках:

```json
{
  "groups": ["Работа"],
  "apps": [
    {
      "id": "my-app",
      "name": "Моё приложение",
      "type": "app",
      "mode": "shortcut",
      "target": "shortcuts/my-app.lnk",
      "icon": "icons/my-app.png",
      "description": "",
      "order": 0,
      "group": "Работа"
    }
  ]
}
```

`order` — целое число: `0`, а не `0.0`. `id` должен быть уникальным. Необязательный `groups` задаёт порядок разделов; пустые разделы скрываются. Плитки без группы идут в «Прочее».

Собственная копия `.lnk` сохраняет браузер, профиль, аргументы и рабочую папку. Исходный ярлык с рабочего стола можно удалить. Удаление приложения или перенос его файлов всё равно требует обновления копии ярлыка. Автоматического импорта нет.

Режимы запуска:

- `shortcut`: относительный путь в `shortcuts/` или абсолютный путь к существующему ярлыку.
- `exe`: `type: "app"`, абсолютный путь к EXE в `target`, при необходимости массив строк `args`.
- `app-mode`: `type: "web"`, HTTP(S) URL в `target`; используется браузер, выбранный в настройках (Chrome или Edge).

Иконки — PNG до 2 МБ внутри `icons/`; при отсутствии показывается DES. Журнал фиксирует принятие команды запуска Windows, но не доказывает готовность сайта или приложения. Повреждённая конфигурация не перезаписывается: при перезагрузке остаётся прошлый список, при старте показывается ошибка и пустая панель.

Не храните пароли, ключи или токены в конфигурации, URL и аргументах. Публикуйте только пустые defaults: содержимое `local/` может попасть в installer и переносимую сборку, даже если папка исключена из Git. Перед публичной сборкой используйте чистую копию.

## Проверки и лицензия

`npm run check` проверяет JavaScript и группировку/слияние конфигурации. `npm test` запускает Rust-тесты валидации, настроек и путей к собственным ярлыкам. Результаты проверки этой копии записаны в [VALIDATION.md](VALIDATION.md).

Исходный код распространяется под [MIT](LICENSE). Зависимости сохраняют собственные лицензии. Личные профили браузеров и приложения в комплект не входят.
